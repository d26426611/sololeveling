# 深層樓層新鮮感：用程序化調整取代持續手工新內容

「無盡爬塔」代表玩家可能打到第 500 層以上，此時已經清完所有 7 個一般區域，進入不斷重複最後一區王的無盡循環（Endless Loop）。若要靠不斷新增手工內容（新怪物、新王、新次元）來對抗這個階段的重複感，需要持續的內容產出，跟另一個目標「系統要容易擴充/修復」直接衝突——擴充意義變成「必須一直寫新內容」而不是「改資料就好」。

決定：長期新鮮感主要由 Procedural Modifier（程序化調整）機制負責，而不是持續手工做新 Dimension。既有的地獄/幻界兩個手工次元維持現狀、數量不再持續擴張，改為程序化調整的套用對象（例如「這次進地獄，傷害雙倍」「這次幻界，掉落 x3 但防禦歸零」），新增花樣只需要在調整表新增一列資料。

配套決定：
- 調整只在 Endless Loop 階段生效，前 7 區的初次攻略保持乾淨、可預期，避免干擾新手學習曲線。
- 進入次元新增一個非自願的「Rift」（裂隙）事件路徑：無盡循環中約 1/40 樓層機率觸發，短暫、有界（數層後自動送回），刻意維持稀有以保留「意外」的情緒份量。此路徑與既有的刻意進入次元方式（業力印記死亡、幻界之鑰）並存，不取代。

若之後發現程序化調整本身也開始重複、失去新鮮感，才需要重新考慮加入更多手工次元或調整生成邏輯本身。
