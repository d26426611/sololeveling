# 核心體驗定位：Roguelite Power-Fantasy，爽感來自獎勵揭曉而非戰鬥過程

戰鬥系統已經是全自動、可跳過動畫的設計。這代表遊戲的情緒核心不能寄託在「觀看戰鬥過程」上——玩家很可能直接跳過。討論後決定明確定位遊戲的核心體驗為 Roguelite power-fantasy compulsion loop（類 Hades 的「再來一把」衝動循環），而非黑暗生存驚悚（類 Darkest Dungeon 的壓迫/緊張感），儘管美術/敘事上仍保留地獄、幻界等黑暗奇幻元素作為風味而非情緒驅動力。

據此，「爽感」設計的主要投資標的是戰鬥結束後的獎勵揭曉（掉落、金幣、稀有度變色、套裝集齊），而不是戰鬥過程本身的演出。戰鬥過程只需要少量關鍵節點的回饋（爆擊、王被擊敗），不追求做成可觀賞的演出。

這個決定會持續影響後續 UI/UX 投資方向：任何「加強戰鬥可看性」的提案都應該先對照這份定位再評估是否值得做。
